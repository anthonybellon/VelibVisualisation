# Archived Scripts

These scripts are kept for reference but are not part of the active pipeline.
They were typically used for one-time data operations or diagnostics.

## Contents

- **checking_closed_stations.py** - Diagnostic script for checking closed stations
- **combine_data.py** - One-time script for combining data files
- **compare_for_missing.py** - Diagnostic script for finding missing data
- **dead_stations.py** - Diagnostic script for identifying inactive stations
- **delete_duplicates.py** - One-time script for removing duplicate records
- **month_spliter_csv.py** - One-time script for splitting data by month
- **prediction_values.py** - Diagnostic script for analyzing predictions

## Note

These scripts may have hardcoded paths and may not work without modification.
They are preserved for reference and potential future use.
